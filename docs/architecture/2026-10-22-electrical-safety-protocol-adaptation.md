# 电气安全测点适配记录（2026-10-22）

## 数据来源与口径

来源：用户提供的《thingsboard平台设备遥测数据测点及其转换字段.xlsx》“匹配结果”工作表。

- 依据“协议键 → 转换后全称”逐行重命名。赋值不调用数值解析、倍率换算、取整或精度函数；字符串仍为字符串，数字仍为数字。
- 原值为 null 或协议表未配置的字段不写入；0、空字符串、N/A 等非 null 原值保留。
- 剩余电流展示单位按照用户再次确认统一为 mA，不乘除任何倍率。其他单位使用工作表。
- 状态与数值按型号分别定义；缺少状态编码说明的开关、保护和使能状态显示原码，不猜测其含义。
- LDH1、LDA1、SFB、SFE 本次无测点表，用户已确认暂不适配。保留现有页面配置；整包转换器仍不接收这些未配置型号。
- E1P1 不在本次工作表中，保留此前确认的 DO1、DI1、DI2、UG 四项同名原值映射。

## 接入链路

- `docs/电气安全MQTT转换器-TBEL脚本.txt` 与同名 JSON 导出同步，处理 header/data 整包结构。
- SFA 独立脚本保留原有 payload/client 接入结构和设备标识规则，字段映射同表；经纬度作为 Longitude/Latitude 遥测原值入库，不再写坐标属性。
- 前端型号数组统一提供实时信息、监测卡片、看板指标、历史回顾中文名和单位。
- 共享 WebSocket 从型号数组导出电气安全订阅键，不重复维护另一套键清单，不另建连接。
- 连续量按同物理量、同单位分组；电压/电流谐波按阶次分组。状态留在实时信息中，经纬度不绘制连续量趋势。
- 地图仅在渲染边界解释 SFA 的 E/W/N/S 坐标字符串，仍复用完整有效遥测优先、服务器属性回退规则，不修改入库原值。

## 后端核对

电气安全 Service 复用 VisibleDeviceContextService，依照用户权限及 productCategory 查询设备；Controller 继续使用现有模块接口。实际遥测键、最新值和历史值由平台原生 EntityService/AttributeService 接口动态读取，后端没有电气安全测点白名单或倍率计算。本次无需新增后端接口或修改原生时序入库实现。

## 发布与验证边界

文件修改不会自动更新平台中已保存的转换器。部署代码后，还需在对应 MQTT 集成中导入/粘贴更新脚本；SFA 使用独立结构时更新其独立脚本。旧历史数据不回写。
