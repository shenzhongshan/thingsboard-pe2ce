# FSS智能型电涌保护器（单相无漏流）（DEM2）MQTT 通讯协议

## 1. 产品说明

| 项目 | 内容 |
| --- | --- |
| 产品名称 | FSS智能型电涌保护器（单相无漏流） |
| 产品型号 | DEM2 |
| 主要功能 | 提供本文件第 3 节所列的 14 项监测数据。 |
| 文档版本 | V1.0 |
| 引用规范 | 《设备MQTT接入协议指南》 |

本文件说明本型号的数据上报格式、测点定义及状态编码。MQTT 连接、认证和主题约定见《设备MQTT接入协议指南》。

## 2. 数据上报报文

### 2.1 完整报文示例

以下为包含全部测点的格式示例，设备编号与读数仅用于说明，并非实际测量记录；客户应读取设备实际返回的数据。

```json
{
  "header": {
    "time": "2026/10/26 11:32:09",
    "client": "KSDCOM1260317001",
    "slaveid": "KSDDEM2260101001"
  },
  "data": {
    "PhAStatus": 0,
    "GndStatus": 0,
    "TripSW1": 0,
    "TripSW2": 0,
    "StrikeCnt": 0,
    "Temp1": 25.5,
    "Temp2": 25.5,
    "SPD_RUL": 100,
    "SPD_Status": 4,
    "SPD_Alarm": 0,
    "SPD_RULA": 100,
    "SPD_Reason": 0,
    "SPD_DeltaT": 0,
    "SPD_RULDay": 3650
  }
}
```

### 2.2 报文结构说明

| 字段 | JSON 类型 | 含义 | 说明 |
| --- | --- | --- | --- |
| header | object | 报文头 | 设备标识与数据时间 |
| header.time | string | 数据时间 | 示例格式为 YYYY/M/D H:m:s；时间口径及时区以通用规范为准 |
| header.client | string | 网关编号 | 上传本报文的网关标识 |
| header.slaveid | string | 子设备编号 | 本次数据对应的设备标识 |
| data | object | 监测数据 | 本型号完整测点见第 3 节 |

## 3. 测点定义

| 序号 | 中文名称 | 协议键 | JSON 类型 | 单位 | 取值说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | A相电压状态 | `PhAStatus` | integer | — | 编码含义见第 4 节。 |
| 2 | 接地状态 | `GndStatus` | integer | — | 编码含义见第 4 节。 |
| 3 | 脱扣1 | `TripSW1` | integer | — | 编码含义见第 4 节。 |
| 4 | 脱扣2 | `TripSW2` | integer | — | 编码含义见第 4 节。 |
| 5 | 雷击计数 | `StrikeCnt` | integer | 次 | 累计次数。 |
| 6 | 温度1 | `Temp1` | number | ℃ | 数值按所列单位表示。 |
| 7 | 温度2 | `Temp2` | number | ℃ | 数值按所列单位表示。 |
| 8 | 剩余寿命 | `SPD_RUL` | number | % | 剩余寿命百分比。 |
| 9 | 设备状态 | `SPD_Status` | integer | — | 编码含义见第 4 节。 |
| 10 | 告警码 | `SPD_Alarm` | integer | — | 编码含义见第 4 节。 |
| 11 | A相健康度 | `SPD_RULA` | number | % | 数值按所列单位表示。 |
| 12 | 退化原因 | `SPD_Reason` | integer | — | 编码含义见第 4 节。 |
| 13 | 温升指标 | `SPD_DeltaT` | number | ℃ | 数值按所列单位表示。 |
| 14 | 剩余寿命天数 | `SPD_RULDay` | integer | 天 | 剩余寿命，以天数表示。 |

数值以 MQTT 报文中的实际值读取，不再按寄存器系数进行二次换算。`integer` 表示整数型 JSON 数字，`number` 表示可含小数的 JSON 数字；单位“—”表示无单位。

## 4. 状态及告警码

### 4.1 A相电压状态（`PhAStatus`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | 报警 |

### 4.2 接地状态（`GndStatus`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | 报警 |

### 4.3 脱扣1（`TripSW1`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | 报警 |

### 4.4 脱扣2（`TripSW2`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | 报警 |

### 4.5 设备状态（`SPD_Status`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 初始化 |
| 1 | 学习中 |
| 2 | 学习保持 |
| 3 | 事件 |
| 4 | 正常 |
| 5 | 观察 |
| 6 | 预警 |
| 7 | 危急 |
| 8 | 故障 |

### 4.6 告警码（`SPD_Alarm`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | PE接地异常 |
| 2 | 电压状态报警 |
| 3 | L1漏流偏高 |
| 4 | L2漏流偏高 |
| 5 | L3漏流偏高 |
| 6 | 温升异常 |
| 7 | 剩余寿命偏低 |
| 8 | 雷击后漏流上升 |
| 9 | 健康度偏低 |
| 10 | 建议更换 |
| 11 | 漏流接近饱和 |
| 12 | 温度高危 |
| 13 | 传感器异常 |
| 14 | 基准学习失败 |

### 4.7 退化原因（`SPD_Reason`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 无 |
| 1 | 漏流 |
| 2 | 温升 |
| 3 | 趋势 |
| 4 | 雷击 |
