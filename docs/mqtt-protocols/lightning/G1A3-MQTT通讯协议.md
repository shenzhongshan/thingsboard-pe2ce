| 文档版本 | V1.1 |
| 引用规范 | 《设备MQTT接入协议指南》V1.0（2026-10-26） |

本文件说明本型号的遥测、设备属性、配置参数及状态编码。连接、认证、自动注册及重连行为见公共指南。只读字段沿用已确认范围；配置及控制项按本型号 Modbus 文档列出，包含 R/W 与 W 项，MQTT 配置键留空。

## 2. 数据上报报文

### 2.1 直连设备遥测

Topic：`topic.telemetry`，缺省为 `v1/devices/me/telemetry`。身份由连接凭据确定。以下示例包含第 3 节全部 5 项测点，读数仅用于说明结构，并非实际采集记录。

```json
{
  "ts": 1792459200000,
  "values": {
    "SampleCnt": 100,
    "SamplePrd": 1,
    "GndVolt": 0.5,
    "GndGridRes": 4.25,
    "ResDecimal": 2
  }
}
```

公共指南第 7 章还允许不带时间戳的键值对象，以及由多个 `ts/values` 对象组成的数组。无时间戳时使用平台接收时间；批量补传保留每条记录原始采集时间。

### 2.2 网关代理子设备遥测

Topic：`topic.gw_telemetry`，缺省为 `v1/gateway/telemetry`。网关使用自身凭据连接，顶层键为子设备名称；示例名称仅作说明，必须与网关上线消息的 `device` 一致，不默认等于 Modbus 站号。

```json
{
  "KSDG1A3260101001": [
    {
      "ts": 1792459200000,
      "values": {
        "SampleCnt": 100,
        "SamplePrd": 1,
        "GndVolt": 0.5,
        "GndGridRes": 4.25,
        "ResDecimal": 2
      }
    }
  ]
}
```

网关订阅成功后先向 `v1/gateway/connect` 发布子设备上线消息，再发布遥测。子设备离线使用 `v1/gateway/disconnect`；网关断开后平台将其子设备视为离线，见公共指南第 9、11 章。

### 2.3 报文结构与数据约定

| 字段 | JSON 类型 | 含义 | 说明 |
| --- | --- | --- | --- |
| ts | integer | 采集时间 | UTC Unix 毫秒时间戳；补传使用原始采集时间 |
| values | object | 测点键值 | 本型号完整字段见第 3 节 |
| 子设备名称 | array | 网关代理的子设备记录 | 仅网关结构使用；一条消息可包含多个子设备 |

## 3. 测点定义

| 序号 | 中文名称 | 协议键 | JSON 类型 | 单位 | 取值说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | 采集次数 | `SampleCnt` | integer | 次 | 累计次数。 |
| 2 | 采集周期 | `SamplePrd` | integer | min | 数值按所列单位表示。 |
| 3 | 地网电压 | `GndVolt` | number | V | 数值按所列单位表示。 |
| 4 | 地网阻值 | `GndGridRes` | number | Ω | 数值按所列单位表示。 |
| 5 | 阻值小数位 | `ResDecimal` | integer | Ω | 阻值小数位信息。 |

数值以 MQTT 报文中的实际值读取，不再按寄存器系数进行二次换算。`integer` 表示整数型 JSON 数字，`number` 表示可含小数的 JSON 数字；单位“—”表示无单位。

## 4. 状态及告警码

本型号无状态及告警码字段。

## 5. 设备属性

公共指南第 8.1 节规定每次连接成功及属性变化时上报设备属性。本型号尚未提供已确认的完整 MQTT 属性键清单；以下仅演示公共指南的 `model` 键与本型号值，不表示固件已实现上报，也不计入第 3 节只读测点数。

| 属性 | MQTT 键 | JSON 类型 | 数据来源与支持状态 | 上报时机 |
| --- | --- | --- | --- | --- |
| 产品型号 | model（公共示例键） | string | G1A3；实际实现待确认 | 公共指南要求上线及变化时，型号支持待确认 |
| 产品序列号 / 固件版本 | 待确认 | 待确认 | 不由遥测字段或凭据推断属性映射 | 待确认 |

直连设备发布到 `topic.attributes_pub`（缺省 `v1/devices/me/attributes`）：

```json
{
  "model": "G1A3"
}
```

网关发布到 `topic.gw_attributes`（缺省 `v1/gateway/attributes`）：

```json
{
  "KSDG1A3260101001": {
    "model": "G1A3"
  }
}
```

序列号即使在 Modbus 中可写，也不代表 MQTT 属性可写；本型号配置及控制项按本型号 Modbus 文档列出，包含 R/W 与 W 项，MQTT 配置键留空。

## 6. 可读写配置参数

### 6.1 参数定义与 Modbus 对照

| 参数及原文约束 | MQTT 配置键 | Modbus 寄存器 | 字长 / 类型 / 权限 | Modbus 系数及单位 | 原文复位值 | 生效条件 | 删除行为 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| SampleCnt：采集次数 |  | D262 / 0x0106 | 1 / int16_t / R/W | 次 | 未注明 | 原文未注明 | 本地缺省值及删除恢复行为待确认 |
| SamplePrd：采集周期 |  | D263 / 0x0107 | 1 / int16_t / R/W | min | 未注明 | 原文未注明 | 本地缺省值及删除恢复行为待确认 |
| Modbus站号 |  | D257 / 0x0101 | 1 / int16_t / R/W | 未注明 | 未注明 | 原文未注明 | 本地缺省值及删除恢复行为待确认 |

### 6.2 配置属性推送与删除

直连设备订阅 `topic.attributes_sub`（缺省 `v1/devices/me/attributes`），平台按公共指南第 8.2 节推送“已确认配置键 → 值”的 JSON 对象。删除推送使用 `deleted` 字符串数组，设备恢复对应本地缺省值。本型号 MQTT 配置键尚未填写，暂不提供可执行参数示例。

网关订阅 `v1/gateway/attributes`，平台推送对象包含 `device`（子设备名称）和 `data`（变化的配置键值对象，或含 `deleted` 数组的对象）。仅向已上线的子设备推送，不能把上报时以子设备名称分组的结构用于下发。

公共指南未定义寄存器写入结果回执。MQTT 投递成功不代表底层写入成功；实际值回读、错误反馈和执行结果通道待确认。

### 6.3 上线查询与配置同步

直连设备上线后向 `v1/devices/me/attributes/request/{request_id}` 发布属性查询，`sharedKeys` 为已确认配置键的逗号分隔字符串；平台在 `v1/devices/me/attributes/response/{request_id}` 返回 `shared` 对象，末级请求序号必须相同。

网关向 `v1/gateway/attributes/request` 发布对象，包含 `id`、`device`、`client: false` 及 `keys` 数组；平台在 `v1/gateway/attributes/response` 原样返回 `id`、`device`，结果放入 `values`。单键查询使用 `key`，应答使用 `value`。查询设备属性时使用公共指南对应的客户端属性查询方式。

以上是公共传输约定，具体查询键待 MQTT 配置键确定后填写。平台返回的是保存的属性，不表示刚刚读取设备寄存器；缺失键按公共指南第 8.3、9.3 节处理。
