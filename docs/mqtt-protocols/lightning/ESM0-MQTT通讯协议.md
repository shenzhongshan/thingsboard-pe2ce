## 2. 数据上报报文

### 2.1 完整报文示例

以下为包含全部测点的格式示例，设备编号与读数仅用于说明，并非实际测量记录；客户应读取设备实际返回的数据。

```json
{
  "header": {
    "time": "2026/10/26 11:32:09",
    "client": "KSDCOM1260317001",
    "slaveid": "KSDESM0260101001"
  },
  "data": {
    "RemoteSig": 0,
    "McbStatus": 0,
    "GndStatus": 0,
    "StrikeCnt": 0,
    "Temp": 25.5
  }
}
```

### 2.2 报文结构说明

| 字段 | JSON 类型 | 含义 | 说明 |
| --- | --- | --- | --- |
| header | object | 报文头 | 设备标识与数据时间 |
| header.time | string | 数据时间 | 示例格式为 YYYY/M/D H:m:s；时间口径及时区以通用规范为准 |
| header.client | string | 网关编号 | 上传本报文的网关标识 |
| header.slaveid | string | 子设备编号 | 本次数据对应的设备标识 |
| data | object | 监测数据 | 本型号完整测点见第 3 节 |

## 3. 测点定义

| 序号 | 中文名称 | 协议键 | JSON 类型 | 单位 | 取值说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | SPD状态 | `RemoteSig` | integer | — | 编码含义见第 4 节。 |
| 2 | 空开状态 | `McbStatus` | integer | — | 编码含义见第 4 节。 |
| 3 | 接地状态 | `GndStatus` | integer | — | 编码含义见第 4 节。 |
| 4 | 雷击计数 | `StrikeCnt` | integer | 次 | 累计次数。 |
| 5 | 温度传感器 | `Temp` | number | ℃ | 数值按所列单位表示。 |

数值以 MQTT 报文中的实际值读取，不再按寄存器系数进行二次换算。`integer` 表示整数型 JSON 数字，`number` 表示可含小数的 JSON 数字；单位“—”表示无单位。

## 4. 状态及告警码

### 4.1 SPD状态（`RemoteSig`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | 报警 |

### 4.2 空开状态（`McbStatus`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | 报警 |

### 4.3 接地状态（`GndStatus`）

编码方式：整数枚举。

| 值 | 含义 |
| --- | --- |
| 0 | 正常 |
| 1 | 报警 |
