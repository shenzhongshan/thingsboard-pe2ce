# FSS智能型电涌保护器（三相全电流）（DEA4）MQTT 通讯协议

## 1. 产品说明

| 项目 | 内容 |
| --- | --- |
| 产品名称 | FSS智能型电涌保护器（三相全电流） |
| 产品型号 | DEA4 |
| 主要功能 | 提供本文件第 3 节所列的 32 项监测数据。 |
| 文档版本 | V1.0 |
| 引用规范 | 《设备MQTT接入协议指南》 |

本文件说明本型号的数据上报格式、测点定义及状态编码。MQTT 连接、认证和主题约定见《设备MQTT接入协议指南》。

## 2. 数据上报报文

### 2.1 完整报文示例

以下为包含全部测点的格式示例，设备编号与读数仅用于说明，并非实际测量记录；客户应读取设备实际返回的数据。

```json
{
  "header": {
    "time": "2026/10/26 11:32:09",
    "client": "KSDCOM1260317001",
    "slaveid": "KSDDEA4260101001"
  },
  "data": {
    "PhAStatus": 0,
    "PhBStatus": 0,
    "PhCStatus": 0,
    "GndStatus": 0,
    "TripSW1": 0,
    "TripSW2": 0,
    "TripSW3": 0,
    "TripSW4": 0,
    "StrikeCnt": 0,
    "LeakCurrA": 30.5,
    "LeakCurrB": 30.5,
    "LeakCurrC": 30.5,
    "Temp1": 25.5,
    "Temp2": 25.5,
    "Temp3": 25.5,
    "Temp4": 25.5,
    "SPD_RUL": 100,
    "SPD_Status": 4,
    "SPD_Alarm": 0,
    "SPD_WorstPh": 0,
    "SPD_RULA": 100,
    "SPD_RULB": 100,
    "SPD_RULC": 100,
    "SPD_Reason": 0,
    "SPD_I1hA": 30.5,
    "SPD_I1hB": 30.5,
    "SPD_I1hC": 30.5,
    "SPD_I24hA": 30.5,
    "SPD_I24hB": 30.5,
    "SPD_I24hC": 30.5,
    "SPD_DeltaT": 0,
    "SPD_RULDay": 3650
  }
}
```

### 2.2 报文结构说明

| 字段 | JSON 类型 | 含义 | 说明 |
| --- | --- | --- | --- |
| header | object | 报文头 | 设备标识与数据时间 |
| header.time | string | 数据时间 | 示例格式为 YYYY/M/D H:m:s；时间口径及时区以通用规范为准 |
| header.client | string | 网关编号 | 上传本报文的网关标识 |
| header.slaveid | string | 子设备编号 | 本次数据对应的设备标识 |
| data | object | 监测数据 | 本型号完整测点见第 3 节 |

## 3. 测点定义

| 序号 | 中文名称 | 协议键 | JSON 类型 | 单位 | 取值说明 |
| --- | --- | --- | --- | --- | --- |
| 1 | A相电压状态 | `PhAStatus` | integer | — | 编码含义见第 4 节。 |
| 2 | B相电压状态 | `PhBStatus` | integer | — | 编码含义见第 4 节。 |
| 3 | C相电压状态 | `PhCStatus` | integer | — | 编码含义见第 4 节。 |
| 4 | 接地状态 | `GndStatus` | integer | — | 编码含义见第 4 节。 |
| 5 | 脱扣1 | `TripSW1` | integer | — | 编码含义见第 4 节。 |
| 6 | 脱扣2 | `TripSW2` | integer | — | 编码含义见第 4 节。 |
| 7 | 脱扣3 | `TripSW3` | integer | — | 编码含义见第 4 节。 |
| 8 | 脱扣4 | `TripSW4` | integer | — | 编码含义见第 4 节。 |
| 9 | 雷击计数 | `StrikeCnt` | integer | 次 | 累计次数。 |
| 10 | A相漏流 | `LeakCurrA` | number | μA | 数值按所列单位表示。 |
| 11 | B相漏流 | `LeakCurrB` | number | μA | 数值按所列单位表示。 |
| 12 | C相漏流 | `LeakCurrC` | number | μA | 数值按所列单位表示。 |
| 13 | 温度1 | `Temp1` | number | ℃ | 数值按所列单位表示。 |
| 14 | 温度2 | `Temp2` | number | ℃ | 数值按所列单位表示。 |
| 15 | 温度3 | `Temp3` | number | ℃ | 数值按所列单位表示。 |
| 16 | 温度4 | `Temp4` | number | ℃ | 数值按所列单位表示。 |
| 17 | 剩余寿命 | `SPD_RUL` | number | % | 剩余寿命百分比。 |
| 18 | 设备状态 | `SPD_Status` | integer | — | 编码含义见第 4 节。 |
| 19 | 告警码 | `SPD_Alarm` | integer | — | 编码含义见第 4 节。 |
| 20 | 最差相 | `SPD_WorstPh` | integer | — | 编码含义见第 4 节。 |
| 21 | A相健康度 | `SPD_RULA` | number | % | 数值按所列单位表示。 |
| 22 | B相健康度 | `SPD_RULB` | number | % | 数值按所列单位表示。 |
| 23 | C相健康度 | `SPD_RULC` | number | % | 数值按所列单位表示。 |
| 24 | 退化原因 | `SPD_Reason` | integer | — | 编码含义见第 4 节。 |
| 25 | A相1小时平均漏流 | `SPD_I1hA` | number | μA | 数值按所列单位表示。 |
| 26 | B相1小时平均漏流 | `SPD_I1hB` | number | μA | 数值按所列单位表示。 |
| 27 | C相1小时平均漏流 | `SPD_I1hC` | number | μA | 数值按所列单位表示。 |
| 28 | A相24小时平均漏流 | `SPD_I24hA` | number | μA | 数值按所列单位表示。 |
| 29 | B相24小时平均漏流 | `SPD_I24hB` | number | μA | 数值按所列单位表示。 |
| 30 | C相24小时平均漏流 | `SPD_I24hC` | number | μA | 数值按所列单位表示。 |
| 31 | 温升指标 | `SPD_DeltaT` | number | ℃ | 数值按所列单位表示。 |
| 32 | 剩余寿命天数 | `SPD_RULDay` | integer | 天 | 剩余寿命，以天数表示。 |

数值以 MQTT 报文中的实际值读取，不再按寄存器系数进行二次换算。`integer` 表示整数型 JSON 数字，`number` 表示可含小数的 JSON 数字；单位“—”表示无单位。
