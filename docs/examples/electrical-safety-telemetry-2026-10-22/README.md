# 电气安全各型号遥测测试报文

报文时间：2026/10/26 09:22:39（UTC+8）。

每个 JSON 文件是一条完整消息，可直接复制到 MQTTX 的 JSON 消息体。主题使用电气安全 MQTT 集成当前配置的订阅主题，脚本本身不限定主题。

## 使用说明

- 这些报文对应 `docs/电气安全MQTT转换器-TBEL脚本.txt` 的 `header/data` 整包入口。SFA 此处也使用整包入口，不用于独立的 `payload/client` 脚本。
- `header.salveid` 是测试设备编号；测试现有设备时替换为真实编号。`header.client` 可替换为实际网关编号。
- `data` 使用转换前的原始协议键；入库后应得到脚本映射的转换后名称，值和类型不变。
- 每条包含该型号全部已配置字段，包含值为 0 的字段。状态码 0 用于验证零值保留，不据此假定所有开关/保护状态的业务含义。
- SFA 数字使用字符串，与之前给出的实际协议结构一致；入库仍应是字符串。经纬度同样保留方向前缀原文。
- LDH1、LDA1、SFB、SFE 缺少测点表，按此前确认暂不生成；E1P1 使用已确认的四个字段。
