# E1A2 电表测试遥测

来源：energy-regulation-measurements.ts 的全部 34 个规范测点；数值不换算。

在 ThingsBoard 中创建/使用 E1A2 测试设备，服务器属性 productCategory=energy_regulation、functionCategory=energy_meter、productName=ESA智能电表，并配置资产归属。使用该设备访问令牌建立标准 MQTT 直连，发布主题 v1/devices/me/telemetry。all-four.json 可一次上报四个历史采样，也可按文件编号依次发布。不要发送到只接收 header/data 的集成转换器；此处是标准设备遥测报文，不是该转换器输入。

时间为生成时刻之前的四个分钟采样，按 Asia/Singapore（UTC+8）展示。重复发送同一文件会写入同一时间戳，不会增加新的采样时间。

| --- | --- | --- | --- | --- |
| 01-normal | 2026-10-26 11:01:42 | 6.9 | 1000 | 0 |
| 02-load-increase | 2026-10-26 11:02:42 | 13.8 | 1000.115 | 0 |
| 03-zero-load | 2026-10-26 11:03:42 | 0 | 1000.345 | 0 |

预期：第一至第四条累计差为 0.345 kWh；相邻增量依次为 0.115、0.230、0 kWh。最新总功率为 0 kW，累计电量仍为 1000.345 kWh，DI1=1，A相电压260V。零负载功率因数1为测试占位，不用于验证零负载功率因数算法。第四条状态/电压变化只验证展示与已配置规则，不保证自动产生告警。

若四条位于同一小时、该测试设备没有其他功率采样，则该小时总功率样本均值为5.175kW；若跨小时则分别计算。当前接口的峰值是小时平均功率的最大值，不应直接预期13.8kW。

当前用电量计算器需要周期开始之前的基线；这四条用于验证区间增量及最新值，不能单独保证今日/本周/本月用电量非空。请使用独立测试设备，避免已有表底影响结果；仅一个可见能源设备时才可以直接将上述值与资产汇总对比。
